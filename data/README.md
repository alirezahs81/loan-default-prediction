# Dataset

The raw `Loan_Default.csv` file is intentionally not committed to this public repository because the supplied project archive did not include a clear redistribution license or permission statement.

The dataset appears to correspond to the [Loan Default Dataset on Kaggle](https://www.kaggle.com/datasets/yasserh/loan-default-dataset). Obtain it directly from the source and review the current license and terms before use. Place the CSV at `data/Loan_Default.csv` locally. Do not redistribute it unless the source terms explicitly permit redistribution.
